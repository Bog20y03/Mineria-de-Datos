# Modelos: Comparativa Multimodelo Supervisada
## 1. Fundamentación Teórica
Un modelo en minería de datos es una función de aproximación que mapea el espacio de características hacia una variable objetivo mediante inferencia inductiva.
## 2. Objetivos del Módulo
Comparar el rendimiento diagnóstico de cuatro familias de modelos (Regresión Logística, Árboles CART, k-NN y Análisis Discriminante Lineal).
## 3. Estructura y Trazabilidad del Tema
- **Búsquedas:** 15 ecuaciones booleanas bilingües con enlaces a Google Scholar.
- **Documentos:** 15 artículos científicos seminales y revisiones sistemáticas con DOI.
- **Dataset:** Datos públicos reales con documentación formal en `datos/metadata.json`.
- **Laboratorio en R:** Script autónomo, reproducible y parametrizado.
- **Resultados:** Gráficos diagnósticos de alta resolución y reporte numérico de métricas.
- **LaTeX:** Avance temático y capítulos compilados para la memoria general.

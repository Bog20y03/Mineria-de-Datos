# Tema 02: Métodos de Minería de Datos
## Visión General
Los métodos representan los algoritmos computacionales y técnicas formales para la extracción de conocimiento.
## Métodos Principales
1. **Clasificación:** Asignación a clases discretas (Árboles, SVM, Redes Neuronales).
2. **Regresión:** Estimación de respuestas cuantitativas continuas.
3. **Clustering:** Agrupamiento no supervisado (K-Means, DBSCAN, Jerárquico).
4. **Reglas de Asociación:** Detección de co-ocurrencias (Apriori, FP-Growth).
5. **Detección de Anomalías:** Identificación de patrones atípicos y valores extremos.

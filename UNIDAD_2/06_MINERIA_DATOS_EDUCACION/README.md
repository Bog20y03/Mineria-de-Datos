# Tema 06: Minería de Datos en la Educación (Educational Data Mining - EDM)
## Objetivos y Alcance
La minería de datos educativa (EDM) y la analítica del aprendizaje analizan datos de interacción en plataformas formativas y sistemas de gestión de aprendizaje (LMS).
## Áreas de Aplicación
1. **Predicción del Rendimiento:** Modelado de notas finales a partir de actividad en foros y cuestionarios.
2. **Detección Temprana de Estudiantes en Riesgo:** Alertas de deserción universitaria antes del abandono efectivo.
3. **Análisis del Comportamiento:** Patrones de navegación y hábitos de estudio.
4. **Sistemas Educativos Inteligentes:** Adaptación personalizada de contenidos pedagógicos.

# Tema 01: Modelos de Minería de Datos
## Concepto Fundamental
Un modelo de minería de datos es una abstracción matemática o computacional que captura patrones estructurales, correlaciones o relaciones de dependencia latentes en un conjunto de datos.
## Taxonomía de Modelos
- **Modelos Descriptivos:** Buscan identificar patrones subyacentes sin una variable objetivo predeterminada (e.g. Clustering, Reglas de Asociación).
- **Modelos Predictivos:** Estiman el valor de una variable objetivo a partir de un vector de atributos independientes (e.g. Clasificación, Regresión).
- **Modelos de Clasificación:** La variable de respuesta es discreta/categórica.
- **Modelos de Agrupamiento:** Agregan instancias por proximidad en el espacio de características.
## Métricas de Evaluación
Exactitud (Accuracy), Sensibilidad (Recall), Precisión, F1-Score, Matriz de Confusión, Curvas ROC-AUC, Coeficiente de Silueta y BSS/TSS.
## Aplicaciones Principales
Segmentación de mercado, detección de fraude, medicina diagnóstica y optimización industrial.

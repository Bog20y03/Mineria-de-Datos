# Etapa 1: Selección y Caracterización de la Base de Datos del Proyecto
## Problema Seleccionado
La deserción universitaria temprana genera impactos académicos y de gestión institucional. Este proyecto evalúa el modelado predictivo del riesgo de abandono estudiantil a partir de indicadores del primer año académico.
## Justificación
Permite a los comités de tutoría y bienestar universitario evaluar la factibilidad de herramientas analíticas para la intervención pedagógica oportuna.
## Ficha Técnica del Dataset
- **Descripción:** Muestra didáctica de 500 registros con estructura inspirada en UCI #697; no verificada como submuestra.
- **Dimensión:** 500 registros y 5 variables predictoras (académicas, sociodemográficas y financieras).
- **Variable Objetivo:** `Abandono_Estudiantil` (0: Continuidad, 1: Deserción).
- **Distribución:** 495 casos negativos (99.0%) y 5 casos positivos (1.0% de prevalencia).

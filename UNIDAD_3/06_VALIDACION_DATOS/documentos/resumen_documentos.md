# Documento Seleccionado - Validación y Detección de Datos Erróneos y Outliers

### [DOC_U3_VAL_001] Statistical Data Cleaning with Applications in R (2018)
- **Autores:** Mark van der Loo, Edwin de Jonge
- **DOI:** [10.1002/9781118897126](https://doi.org/10.1002/9781118897126)
- **Objetivo:** Sistematizar el tratamiento formal de errores, inconsistencias y outliers en R.
- **Resultados:** Directrices metodológicas reproducibles para certificar la integridad de bases de datos antes de modelar.

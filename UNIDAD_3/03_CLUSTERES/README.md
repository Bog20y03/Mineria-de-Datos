# Clústeres y Segmentación Mayorista
## 1. Descripción
Este tema implementa una técnica de minería de datos aplicada sobre datos reales y públicos.
## 2. Recursos Disponibles
- Búsquedas académicas estructuradas con Google Scholar.
- Documentación del dataset público en `datos/metadata.json`.
- Script ejecutable en R con generación de gráficos y métricas.
- Capítulo LaTeX de documentación.
